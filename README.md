# Adel

Проект лендинга для курса «Путешествие к Самости».

## О проекте

Этот репозиторий содержит спецификацию, план реализации и материалы для создания одностраничного лендинга с акцентом на доверие к эксперту, прозрачную подачу продукта и конверсию в заявку.

## Содержимое

- спецификация проекта
- план реализации
- структура контента и приоритеты для запуска версии v1

## Следующий шаг

Дальше можно перейти к реализации дизайна и фронтенда на основе подготовленного плана.
